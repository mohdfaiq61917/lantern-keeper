# Lantern Keeper

Lantern Keeper is a top-down survival game built with vanilla JavaScript, HTML5 Canvas, and the Web Audio API. You play as a keeper surviving the dark by keeping a lantern lit while shadow enemies emerge from the night.

## Features

- Endless survival gameplay with escalating difficulty
- Four enemy archetypes: chaser, swarmer, tank, and shooter
- Lantern auto-fire, XP collection, and level-up upgrades
- Procedural audio that intensifies as threat rises
- Responsive canvas and safe localStorage unlock tracking
- Unit tests for RNG and upgrade logic

## How to run

1. Download or clone this repository.
2. Open `index.html` directly in a modern browser.
3. Use WASD or arrow keys to move and the mouse to aim the lantern.

## Controls

- Move: WASD or arrow keys
- Lantern aim: mouse position
- Pause: Escape
- Upgrade selection: 1/2/3 when the upgrade screen appears

## Notes

This phase establishes the project structure and a playable core loop. It is intentionally lightweight and designed as a starting point for the richer systems in the later phases.
